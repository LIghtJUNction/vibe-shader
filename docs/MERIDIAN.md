# 天穹折光：实现说明

目标是让天象成为辨识点，同时留住普通方块的材质，不再用描边、闪屏、满屏染色或高 Bloom 代替设计。

## 数据流与边界

`lib/sky.glsl` 仅负责公共输入、按维度选择模块及天空/雾 API。`lib/sky/{overworld,nether,end,stars}.glsl` 分别管理维度天空与星光；未选中的维度由预处理器排除。

`lib/celestial.glsl` 用世界固定轴上的方向点积构建丝带，没有经度 atan 分支接缝，也不读取屏幕 UV、上一帧或新增贴图。天空主路径和水面反射均经由 `renderDimensionSky`，不单独复制反射里的天象算法。

`renderDimensionFog` 只返回大气颜色。原先下界/末地地形雾直接取完整天空；现在它不包含星点、火星、光带或暗核，避免天体变成穿过远景的雾纹理。

`lib/tidal.glsl` 是独立水面发光项，Composite 根据真实透明表面位置调用。域扭曲打散规则波纹，距离、厚度、水平度、昼夜、维度和用户强度门控后才计算细节；不新增渲染目标或历史缓冲。它不判断生物群系或玩家动作，夜间洞穴水平水面仍可能出现微光。

末地的星光偏转使用切平面近似，吸积盘和弧光也是艺术化模型，不是物理正确黑洞模拟。固定方向为归一化 `(0.18, 0.24, -1.0)`；先排除背面，再进行投影，防止另一半天空出现重复天体。

## 保留的兼容策略

不改 `world0/world-1/world1` 入口契约，不改透明几何的 colortex3/4/7 归属、逐缓冲混合回退和手持物路径。保留平坦水面几何、薄瀑布吸收厚度上限、磨砂普通方块、发光矿物默认关闭和 High 的 TAA 默认关闭。

水面法线改为原有三项高度波函数的解析导数：从四次高度求值共 12 次正弦改为 3 次余弦。测试对实际 GLSL 高度做中心差分验证，避免另写一份 Python 模型自证。这是局部算术缩减，不代表整个游戏帧率提高四倍。

## 手动观看

主世界暮色或夜晚面向负 Z，略抬头，丝带从侧面延伸到上方；在开阔水域可观察天空倒影。夜海微光应在近处间歇显现，而非整片白亮。末地同样主要面向负 Z 附近寻找观测站天体。

设置页新增天象细节、强度、夜海微光、流速，中英文均已接线。旧四种 Vibe 模式保留；新增第 5 种 Meridian 为预览分支默认。天象细节 0 与微光 0 是相互独立的开关；流速 0 不冻结旧有水波、星光、云和昼夜。

## 复现

`tools/render_preview.py` 直接执行这些 GLSL，保留 HDR float 像素用于测试，PNG 仅使用 ACES 曲线及 gamma 便于观察。预览明确标注非 Minecraft 截图，示意无限水面不等于完整游戏合成。完整验收边界见根目录 `VALIDATION.md`。
